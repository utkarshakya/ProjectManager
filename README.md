# Project Manager Application

## Overview

This is a full-stack Project Manager application designed to help users manage their projects and tasks efficiently. The application includes user authentication, project management, and task tracking features.

## Features

- User authentication (login, registration)
- Protected routes for authenticated users
- Create, update, and delete projects
- Add, update, and delete tasks within projects
- Responsive user interface

## Installation

### Prerequisites

- Node.js (v16 or later)
- MongoDB

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/utkarshakya/ProjectManager.git
   cd ProjectManager
   ```

2. Install dependencies for both client and server:

   ```bash
   npm install
   ```

3. Set up environment variables:
   - Create a `.env` file, take reference from this [`.env.example`](./.env.example) file.

4. Start the project in development mode:

     ```bash
        npm run dev
     ```

5. Open the application in your browser at `http://localhost:5173`.
